# 仕様（現行実装）

## 入力形式

- `.gpx` / `.tcx` を複数選択、ドラッグ＆ドロップで読み込む。サンプルは `public/samples/` に登録済みの4つの `yymmdd.gpx` を読み込む。
- GPXの `trk/trkseg/trkpt` に対応。トラックに有効なポイントがない場合のみ `rte/rtept` を利用。
- TCXの `Track/Trackpoint/Position` に対応。ラップごとのトラック境界を保ち、離れた区間を直線で結ばない。
- XML形式不正、未対応形式、描画可能な2点以上の区間が無いファイルはエラーとして表示。
- 座標範囲外の点は読み飛ばし、表示可能な2点未満の区間は除外。
- 同じ `ファイル名 + バイト数 + 更新日時` の組み合わせを同一ファイルとみなし、重複読み込みを防止。

## サンプルファイル

- ファイルは `public/samples/YYMMDD.gpx` に配置する。数字6桁と小文字 `.gpx` のみ自動検出。
- 現在の登録：`211120.gpx`、`211204.gpx`、`220619.gpx`、`220706.gpx`。
- `pnpm dev` または `pnpm build` の実行時にファイル一覧 `public/samples/index.json` を生成する。生成物はGit管理しない。
- サンプルボタンで対象の最大4件を読み込み、通常のファイル読み込み機能と同じパーサー・経路表示を使う。
- 登録数0件なら未登録メッセージ、1～4件なら登録済みの分のみ表示、5件以上はビルドを失敗させる。
- 公開Pagesの `samples/*.gpx` は第三者からダウンロードできるため、公開前に位置・時刻情報を確認する。

## 集計と表示

- 複数経路を色分けしてLeaflet地図に表示。表示／非表示、記録の削除、個別フォーカス、全経路へのフィット。
- 経路色は初期状態で固定パレット。距離別／獲得標高別の2つのトグルボタンで5段階自動色分けし、再押下で既定色に戻す。
- 自動着色は1ライドにつき1色。距離（km）は[0,50,100,150,200]、獲得標高（m）は[0,500,1000,1500,2000]を境界とする5区分。水色 `#38BDF8`、緑 `#16A34A`、黄 `#EAB308`、オレンジ `#F97316`、赤 `#EF4444`。
- 獲得標高不明（`null`）と不正値は灰色 `#94A3B8`（0mは水色）。区分は固定で、表示／非表示や読込件数によって変えない。
- 各ライドのプルダウンで上記5色を手動指定すると自動着色より優先し、「自動／既定色に従う」で解除可能。ページ内のみ保持。
- 自動モードで地図上に凡例を表示。地図と一覧の色は共通ロジックで一致させる。
- ファイルを追加したとき、および明示的にズーム指示したときだけ表示範囲を再調整。チェックボックス操作で地図のズームを勝手に変更しない。
- 各ファイルの走行距離を表示。画面上部には読み込み件数、表示中の獲得標高、表示中の走行距離を表示。非表示の記録は距離・獲得標高の合計に含めない。
- 獲得標高は標高データがある表示中の記録だけを合算し、その件数を併記する。表示中の記録に有効な標高データがない場合は「— m」を表示する。
- 各ファイルの日時、経過時間、GPSポイント数、獲得標高を表示（取得可能な項目のみ）。
- 日時は走行点の最も早い記録時刻を優先し、GPX `metadata/time`、TCX `Activity/Id` の順にフォールバック。
- 経過時間は走行点の最初と最後の記録時刻の差。休憩時間を含む場合がある。
- 距離はWGS84の緯度経度から球面上のhaversine距離を区間内で積算した概算。
- 獲得標高は同一区間の連続点にある標高差の正値を足したもの。GPS高度のノイズは補正しない。
- 一覧は日時降順。日時のない記録は末尾。

## 制限・プライバシー

- ファイルを外部へアップロードせず、サーバーやブラウザのストレージにも保存しない。再読み込みでログが消える。
- XML解析・描画はブラウザ内で実行。巨大なログでは処理時間やメモリの負担が増える。
- 地図タイルとLeafletの外部CDNの取得にはインターネット接続が必要。
- GPS情報の欠落やドリフトなどにより走行距離・標高が実測値と異なる場合がある。
- 速度推移、期間検索、ログ保存は未実装。
