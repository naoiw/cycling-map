# CYCLING MAP

サイクリングコンピュータなどから出力した GPX / TCX 形式の走行ログを、地図上に重ねて確認するブラウザツールです。旧 [JourneyMap](https://github.com/naoiw/JourneyMap) を参考に React + TypeScript で作り直しました。

## 公開URL

| 環境 | ブランチ | URL |
| --- | --- | --- |
| 本番 | `main` | https://naoiw.github.io/cycling-map/ |
| 開発プレビュー | `develop` | https://naoiw.github.io/cycling-map/develop/ |

## 主な機能

- GPX・TCXファイルの複数選択、ドラッグ＆ドロップ、日付名GPXのサンプル表示
- OpenStreetMap上に複数経路を色分けして重ね描き。距離別／獲得標高別の5段階自動着色、各ライドの手動色指定に対応
- 背景のOpenStreetMapタイルのみ「カラー／グレースケール」を切替可能（初期状態はグレースケール）。経路線はカラーのまま
- 経路ごとの表示切り替え、個別の経路にズーム、全経路にフィット
- 各走行の日時・経過時間・走行距離・ポイント数・獲得標高（記録がある場合）
- 表示中の走行距離と獲得標高を集計。獲得標高は標高データがある記録のみ合算し、データがない場合は「—」を表示
- 表示中ライドの「地図をPNG保存」「統計付きPNG保存」（1600×900、OpenStreetMap帰属表示付き）
- スマートフォンを含むレスポンシブUI

公開用サンプルGPXは `public/samples/` に4件登録しています。

## サンプルGPXの登録

[public/samples/](public/samples/) に、`yymmdd.gpx` 形式のGPXを最大4ファイル配置します。

現在は以下の4件が登録されています。

```text
public/samples/
  211120.gpx
  211204.gpx
  220619.gpx
  220706.gpx
  README.md
```

- 「サンプルの経路を表示」を押すと、4件すべてを読み込みます。
- ファイル名をコードに追加する必要はありません。`pnpm dev` / `pnpm build` で自動検出されます。1～3件でも利用でき、5件以上はビルドエラーになります。
- 追加・入れ替えはまず `develop` にpushし、PRを `main` にマージして公開してください。
- **公開サンプルGPXはGitHub Pages上から誰でもダウンロードできます。** GPS座標・日時などを一般公開してよいか必ず確認してください。

詳細は [public/samples/README.md](public/samples/README.md) を参照してください。

## 操作方法

1. 「ファイルを選択」またはドラッグ＆ドロップで `.gpx` / `.tcx` を読み込みます。サンプルを使って動作確認することもできます。
2. 記録名を押すと経路にズームします。チェックを外すとその経路を非表示にできます。
3. 「全経路に合わせる」で表示中の経路全体へズームします。記録を表示・非表示にしても、手動の地図位置・縮尺は維持されます。
4. 色分けは「手動」「距離別」「獲得標高別」の3ボタンで切り替えます。初期状態は「手動」で、ライドごとのプルダウンから色を指定できます。距離別・獲得標高別では色が数値に応じて自動決定され、手動プルダウンは無効になります。手動モードに戻すと、以前指定した色を再び表示します。
5. 「地図背景」の「カラー／グレースケール」を切り替えます。初期状態はグレースケールで、走行経路の線や凡例は常にカラーのままです。切替によって地図のズームや位置は変わりません。
6. 地図の下にある「地図をPNG保存」「統計付きPNG保存」で表示中の経路全体を1600×900のPNGとして保存できます。後者にはライド数・走行距離・獲得標高が含まれます。非表示の経路は対象外です。**PNGの地図背景にも現在の表示モードが反映**されます。
7. 記録を個別に削除、またはまとめて消去できます。

**プライバシー:** ファイル解析はブラウザ内で完結し、サーバーへアップロードしません。ログは保存されず、ページ再読み込みで消去されます。地図タイル（OpenStreetMap）と地図ライブラリ（Leaflet）の取得には外部への通信が発生します。

**注意:** 距離はGPS座標から計算した概算です。機器側の距離・標高表示と一致しない場合があります。画像保存はその操作時に地図タイルを読み込むためインターネット接続とタイルのCORS許可が必要です。失敗時はエラーを表示し、不完全なPNGは保存しません。保存した画像には経路の位置情報が含まれます。

## 経路の色分け

- 距離別：0～50km未満＝水色、50～100km未満＝緑、100～150km未満＝黄、150～200km未満＝オレンジ、200km以上＝赤。
- 獲得標高別：0～500m未満＝水色、500～1,000m未満＝緑、1,000～1,500m未満＝黄、1,500～2,000m未満＝オレンジ、2,000m以上＝赤。標高情報がない場合は灰色です（0mとは区別）。
- 境界値は上の区分に含めます（50kmちょうどなら緑）。区分と色は地図上の凡例に表示します。
- 初期モードは「手動」。水色・緑・黄・オレンジ・赤の5色を各ライドのプルダウンで指定できます。未指定なら従来の既定パレットを使います。
- 「距離別」「獲得標高別」モードではプルダウンを無効化し、手動色を無視して固定区分に従います。再度「手動」にすると以前の手動設定が復元されます。
- 色設定はブラウザ内で一時的に管理します。再読み込みではリセットされ、ファイルの中身は変更しません。

## 技術スタックとローカル開発

- React 18 / TypeScript 5.6 / Vite 6
- Leaflet 1.9.4（CDN）、OpenStreetMap標準タイル
- Node.js 26 / pnpm 9.14.2

```sh
npm install --global pnpm@9.14.2
pnpm install --frozen-lockfile
pnpm dev     # ローカルで起動
pnpm test    # 地理計算・集計・経路色の自動テスト
pnpm build   # 型チェックと本番ビルド
```

## コード構成

- `src/App.tsx` — ファイルの読み込みと走行記録の状態管理
- `src/MapView.tsx` — Leafletの地図表示、表示範囲の制御
- `src/lib/parser.ts` — GPX / TCXのXML解析
- `src/lib/geo.ts` — 緯度経度からの距離計算
- `src/lib/rideStats.ts` — 表示中の記録に基づく走行距離・獲得標高の集計
- `src/lib/exportGeometry.ts` — PNG用の表示対象・地図範囲・統計・ファイル名計算
- `src/lib/exportPng.ts` — 選択した背景モードでCanvasにPNGを生成・ダウンロード
- `src/lib/mapStyle.ts` — 地図背景モードの型、初期値、タイル描画用フィルター
- `src/lib/rideColors.ts` — 既定色、距離／獲得標高の固定区分、手動指定を統合する色決定ロジック
- `public/samples/` — 公開サンプルGPX（4件）
- `scripts/generate-sample-index.mjs` — サンプル一覧の自動生成
- `tests/` — Node.jsによる地理計算のテスト
- `.github/workflows/` — CI・GitHub Pagesデプロイ
- `docs/` — 仕様と開発資料
