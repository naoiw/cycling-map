# 公開サンプルGPX

このフォルダのGPXを、トップページの「サンプルの経路を表示」ボタンで読み込みます。

現在登録済み：

- `211120.gpx`
- `211204.gpx`
- `220619.gpx`
- `220706.gpx`

ファイル名は **yymmdd.gpx**（6桁の日付と小文字の拡張子）としてください。日付は変更可能です。1～4件の登録を認め、5件以上を検出するとビルドに失敗します。ファイル名をプログラムへ書き足す必要はありません。

`pnpm dev` または `pnpm build` で、登録済みファイルの一覧 `index.json` を自動生成します。生成ファイルはGit管理外で、GitHub PagesではGPXと一緒に公開されます。開発サーバー起動後の変更はサーバーを再起動してください。

**注意：公開リポジトリおよびPagesに置いたGPXには第三者が自由にアクセスできます。** 緯度経度・日時・自宅付近の移動履歴など、公開してよい内容か事前に確認してください。
