# 仕様

## 入力

- 複数ファイル `.gpx` または `.tcx` を選択・ドラッグ＆ドロップして取り込む。
- GPX 1.1 の `trk/trkseg/trkpt` を優先し、経路情報が無ければ `rte/rtept` を解析。
- TCX v2 の `Track/Trackpoint/Position` を解析。ラップやトラックの境界を保つ。
- XMLが不正、非対応形式、各区間に2点以上の有効座標が無い場合はファイルごとにエラー表示。
- 同一ファイル名・ファイルサイズ・更新時刻の組み合わせは重複として扱う。

## 表示

- GPX / TCX 経路をOpenStreetMap上に重ね描く。
- 各ファイルの表示／非表示、クリックによる範囲拡大、一括表示／非表示、全経路に合わせる。
- 日時はGPS測位点の時刻を優先し、GPX metadata/timeやTCX Activity/Idを補助に使用。
- 距離はGPS座標間のhaversine距離を積算。区間境界はつながない。
- 経過時間は時刻を持つ測位点の最初と最後との差。休憩時間を含む場合がある。
- 標高上昇量は連続点間の正の標高差を積算。ノイズ補正はしていない。
- ファイル数、全ファイル合計距離、表示中の合計距離を表示。
- 記録は日時の新しい順。時刻情報なしの記録は末尾に表示。

## 制限事項

- データはメモリ内のみで永続化しない。外部APIへのファイル送信無し。
- 距離・標高・時間は入力ログに依存し、機器の積算値とは一致しない場合がある。
- 地図・Leafletライブラリの取得にはインターネット接続が必要。
- 一般的なGPSログを対象とし、非常に大きいファイルの読み込みには時間がかかる。
- 将来の候補: 時間/速度推移、経路別の色の指定、重複検出の高度化、GPX/TCX詳細情報、保存・検索。
